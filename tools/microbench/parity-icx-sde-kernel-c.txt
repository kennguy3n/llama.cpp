=== SDE -clx (Cascade Lake = AVX-512F+BW+VL+VNNI, NO AVX-VNNI) parity ===
Cascade Lake is the canonical host class for Kernel C: it has the AVX-512
VNNI features Kernel C needs but lacks the VEX-encoded AVX-VNNI variant of
Kernel B. Today these hosts use single-row AVX-512 vec_dot for Q1_0_g128;
Kernel C is the proposed alternative.
